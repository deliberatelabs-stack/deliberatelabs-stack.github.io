Get Started View on GitHub

Why CiteLens?

As AI-powered search becomes mainstream, understanding how your content is being cited by AI is crucial for SEO. CiteLens bridges the gap by connecting your AI assistant directly to your site data.

Webmaster Tools Access

Query traffic stats, keyword rankings, crawl issues, and page performance directly from your AI assistant.

IndexNow Submission

Submit URLs for instant indexing across search engines. Submit up to 10,000 URLs in a single batch.

AI Citation Analysis

Import CSV/XLSX exports from AI Performance reports to see which pages AI is citing and trending queries.

Historical Snapshots

Save weekly stats locally (since API data updates weekly with no date parameters) and diff changes over time.

Quick Start

Run with npx

No installation required. Just add to your MCP client config:

{
  "mcpServers": {
    "citelens": {
      "command": "npx",
      "args": ["-y", "citelens-mcp"],
      "env": {
        "BING_WEBMASTER_API_KEY": "your-api-key-here"
      }
    }
  }
}

See the documentation for full setup instructions.

Who Is This For?

  • SEO professionals who want to query site data conversationally
  • Content teams tracking how AI surfaces their pages
  • Developers who prefer CLI/AI workflows over dashboards
  • Site owners who want instant URL indexing via IndexNow

27 Tools Available

CiteLens provides 27 tools across four categories:

  • 12 Webmaster Tools – site list, traffic, keywords, pages, crawl stats, sitemaps, URL submission
  • 4 IndexNow Tools – generate key, validate, submit URL, batch submit
  • 8 AI Citation Tools – import reports, top pages, trends, queries, intents, topics
  • 3 Snapshot Tools – save, list, and diff historical data
